# Contributing

Use the Python and dashboard commands in the [README](README.md). Add a hermetic regression for behavior changes. Keep provider authentication, original-source verification, authentic audio timing, review authority, visual safety and delivery idempotency intact.

Use invented fixture text, filesystem fakes and mocked providers. Public pull requests must run without deployment credentials. A workflow test run using an operator account can still upload media. Keep third-party source packages, production receipts, account identifiers and generated Reels outside contributions.

Document the checks performed and any behavior you could not exercise. Run `git diff --check` before submitting. Report security issues through the [security policy](SECURITY.md).
