# Architecture

The dashboard is a server-side Next.js application. It authenticates administrators, stores application settings in Supabase, displays run and delivery records, and can dispatch approved workflows to the operator's private GitHub repository.

Local Python workers discover Pexels and Pixabay video candidates and inspect the complete source for people, faces and supported animal classes. GitHub Actions can perform the same qualification. Credentials and the resulting evidence stay in the operator's installation.

The GitHub Reel worker validates the selected Quran Foundation text, Rowwad version and source hashes, and MP3Quran recitation and ayah timing. The renderer checks text fit and uses a verified alignment when needed. FFmpeg produces a 1080 × 1920 video. The final composite must pass computer-vision checks before the release path can use it.

B2 stores final media. Optional Buffer delivery uses separate Facebook and Instagram states. The database binds claims to the selected catalog members and records verified delivery. The scheduler can be driven by one installation-owned Supabase heartbeat. Archiving is optional.

The graphical source diagrams show the [component relationships](docs/diagrams/architecture.mmd) and the [local and hosted worker responsibilities](docs/diagrams/execution-backends.mmd).
