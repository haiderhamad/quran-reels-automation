Where do screened backgrounds come from?

Before a Reel run, a local Mac or GitHub Actions can nominate Pexels and Pixabay clips. Full-source vision checks screen for people, faces and supported animal classes. Supabase records each verified clip’s identity and hash for the worker.

Which Quran sources does the worker check?

Arabic comes from Quran Foundation, Rowwad translations from QuranEnc, and recitation and timing from MP3Quran. The worker checks text fit and uses reviewed phrase alignment when needed.
